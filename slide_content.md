## Slide 6: Technical Architecture
**Technology Stack**

**Frontend:**
- React 19 with TypeScript
- TailwindCSS 4 for elegant styling
- shadcn/ui components
- Framer Motion animations

**Backend:**
- Express.js server
- tRPC for type-safe APIs
- Drizzle ORM for database

**Database:**
- MySQL/TiDB
- Optimized schema with proper indexing

**Authentication:**
- Manus OAuth integration

---

## Slide 7: Database Design
**Data Model**

Core Tables:
- **users** - User accounts with roles (admin/user)
- **vehicles** - User vehicle information
- **parkingFacilities** - Parking locations
- **parkingSlots** - Individual parking spaces
- **bookings** - Parking reservations
- **bookingHistory** - Booking status tracking
- **analyticsData** - Usage statistics
- **pricingRules** - Dynamic pricing configuration
